## 目标

90 天内将 Java 后端经验延伸到企业级 AI Agent 应用：交付一个可运行、可评估、可演示的作品，完成简历和求职闭环。周期：2026-10-10 至 2027-01-07。按每天约 3 小时、每周 6 天规划；每周保留一天休息或补进度。计划是行动目标，不承诺 Offer。

## 作品主线

围绕一个模拟的「企业工单与慢 SQL 诊断助手」逐步升级：V1 工具调用 → V2 RAG 知识助手 → V3 MCP + Spring Boot 业务流程 Agent。使用模拟或脱敏数据；权限、事务、幂等由业务服务保障。

## 阶段里程碑

- 第 14 天：FastAPI + LLM + 安全工具调用 V1。
- 第 28 天：LangGraph 多步任务、状态恢复、审批与幂等。
- 第 42 天：带评测、引用、拒答和权限过滤的 RAG。
- 第 56 天：MCP + Java 服务 + 人工审批业务闭环。
- 第 70 天：可观测性、安全测试、部署与故障演练。
- 第 84 天：作品集、简历、模拟面试与持续投递。
- 第 90 天：干净部署、故障演练、项目演示和复盘。

## 使用方法

1. 在「学习计划」数据库中按「方向 = AI Agent」筛选；用「按状态」看板看进度，用「全部」表格看截止日期。
2. 每周开始时只把当前周状态改为「进行中」；完成任务时勾选清单，并在每日执行记录填时长、产出和证据链接。
3. 每周末填写复盘。未达验收时先补关键项，不要为追日历直接跳到下一阶段。
4. 简历、指标和项目成果必须能指向代码、测试、评测报告或演示，不填写未经验证的数据。

## 每周节奏

学习日约 3 小时：30 分钟原理与文档 + 100 分钟编码 + 35 分钟测试调试 + 15 分钟复盘/面试。每周约 18 小时；预留一天休息或补进度。第 3 周开始市场调研，第 5 周开始定向投递。
